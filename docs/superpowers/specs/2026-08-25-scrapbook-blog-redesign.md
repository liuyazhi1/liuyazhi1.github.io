# 钱钱的 Pipeline 手账：博客视觉与交互改版设计

## 1. 目标

将现有 Hexo + Stellar 博客改造成兼具个人介绍、技术文章索引和项目展示的 Pipeline TD 个人站。视觉采用“古早 QQ 空间 × 手账贴纸”，保留鲜明个人感，同时确保技术文章、目录与代码块适合长时间阅读。

本次改版不改变文章 Markdown 内容，不替换 Hexo，也不重写整个 Stellar 主题。成功标准如下：

- 首页在首屏说明作者身份、技术方向与网站用途。
- 访客能按 Maya、Unreal、Deadline、Omniverse 和数据库快速找到内容。
- 首页同时展示最新文章和精选项目。
- QQ 空间元素形成真实的模块与交互，而不是只作为背景装饰。
- 文章页保持清晰、稳定、可复制代码和可使用目录。
- 桌面、平板和手机均无横向溢出，键盘焦点清晰，并尊重减少动态效果设置。

## 2. 改版范围与技术策略

采用“保留 Stellar 阅读系统，定制首页和全局控件”的混合方案：

- 继续使用 Hexo 7.3 与 Stellar 主题生成文章、归档、分类、标签、目录和代码块。
- 定制首页布局，使首页不再受默认文章列表结构限制。
- 通过站点配置、自定义样式和少量前端脚本实现统一视觉、筛选、空间工具盒与动效。
- 文章页只调整外观和辅助控件，不改变 Markdown 渲染接口。
- 不直接改写第三方主题的核心逻辑；定制代码放在站点可维护的覆盖层中，降低后续主题升级成本。

## 3. 视觉方向

### 3.1 核心概念

站点命名为“钱钱的 Pipeline 手账”。页面像一张持续生长的技术工作手账：文章是便签，分类是票根，个人信息是拍立得，项目是相册，QQ 空间功能集中在底部工具盒。

独特标志是“技术内容使用不同纸张物件表达”：

- 个人简介：略微倾斜的拍立得。
- 技术分类：可点击的票根。
- 最新文章：三色便签。
- 精选项目：项目相册照片。
- 学习状态与短消息：带图钉或胶带的纸条。
- 音乐、访问、留言和返回顶部：底部“空间工具盒”。

所有倾斜和层叠只用于内容边界；正文、代码和关键操作保持水平。

### 3.2 配色

采用已确认的 A“紫粉星梦”：

- 导航紫灰：`#8F6F91`
- 墨色正文：`#42374B`
- 手账底纸：`#F3ECF2`
- 薰衣草：`#D7C7E7`
- 樱花粉：`#F4CADA`
- 雾蓝：`#C8DBEA`
- 便签黄：`#FFF7BD`
- 正文纸白：`#FFFDF8`

深色模式使用“夜间手账”，以深紫背景、低亮灰粉纸张和高对比代码块重新映射颜色，不做机械反色。

### 3.3 字体与图形

- 中文正文使用系统中文无衬线字体，保证加载速度与阅读稳定性。
- 英文标签、日期、技术标识使用等宽字体，呼应 Pipeline 工具界面。
- 手账标题使用有限度的手写感字体；若字体加载失败，回退至可读的圆体或系统字体。
- 图标使用统一线性图标或文本符号，贴纸图形控制在月亮、胶带、图钉、星星、音乐与访客等主题内。
- 不使用大量不同风格的 Emoji 作为正式图标，避免视觉语言混乱。

## 4. 首页结构

### 4.1 顶部导航

顶部依次提供品牌、主页、技术日志、项目相册、关于我和留言板。右侧提供全文搜索与深浅色切换。手机端折叠为菜单，搜索与菜单始终可达。

### 4.2 个性横幅

横幅展示站名“钱钱的 Pipeline 手账”、一句说明和当前学习状态。文案为：

> 今天也在把麻烦的制作流程，变成顺手的小工具。

横幅允许胶带、涂鸦和签名便签形成层次，但不能遮挡标题或导航。

### 4.3 三栏手账区

桌面端使用三栏：

- 左栏：拍立得个人卡、技术分类票根和最近访客。
- 中栏：定位说明、主要行动按钮和最新技术日志。
- 右栏：精选项目相册、留言便签和今日状态。

内容优先级为中栏最高、左栏其次、右栏辅助。平板端变为两栏，手机端变为单栏，顺序为定位说明、最新文章、分类、项目、个人信息、访客与留言。

### 4.4 分类与文章

分类票根链接到对应分类或筛选结果。初始分类为 Maya、Unreal、Deadline、Omniverse 和数据库；不存在文章的学习中分类允许展示“学习中”，但不伪造文章数量。

最新文章便签显示日期、标题、摘要和最多三个标签。便签颜色只表达层次，不承担分类语义；分类必须始终以文字显示。

### 4.5 项目展示

项目相册优先展示 UE 渲染农场提交面板和 Maya 资产批量分发工具。每张项目卡显示项目名、技术栈和详情入口。项目内容来自独立项目页或现有文章，不维护重复正文。

## 5. 文章阅读页

文章页保留手账背景，但正文放在稳定、水平、无纹理的正文纸上。阅读区域采用受控最大宽度，并保持足够的行高。

- 标题区显示分类、标题、发布日期、更新时间和预计阅读时间。
- 正文支持标题层级、引用、图片、表格、链接和代码块。
- 代码块使用深色高对比背景，保留语言标签和复制按钮。
- 桌面端目录跟随滚动；移动端目录折叠为正文上方的可展开控件。
- 作者卡、胶带与图钉只出现在正文边缘，不插入文字行之间。
- 文末显示标签、上一篇/下一篇和相关文章。

## 6. 空间工具盒

底部“空间工具盒”是 QQ 空间体验的集中入口，默认收起，包含：

- 音乐：显示曲名、播放/暂停、上一首、下一首和音量。必须由用户点击后播放，不自动播放。音量偏好存储在浏览器本地。
- 访问：显示总访问量和最近访客入口。没有可靠数据源时显示“访问统计未启用”，不得生成虚假数字。
- 留言：打开现有评论/留言能力；未配置服务时显示配置提示，不展示不可用的提交表单。
- 返回顶部：文章滚动超过一屏后显示。

页面切换不强制续播音乐。若未来启用 PJAX，可在不违反浏览器播放策略的前提下保持播放器状态；当前版本不为此增加复杂依赖。

## 7. 搜索与导航状态

搜索使用 Stellar 已有能力或与 Hexo 静态索引兼容的方案。搜索层支持键盘打开、关闭、结果导航与 Escape 退出。

异常与空状态均使用简洁便签提示：

- 搜索无结果：提示调整关键词或浏览分类。
- 音乐文件缺失：隐藏播放按钮并显示“音乐暂未放入”。
- 访问统计不可用：显示未启用状态。
- 留言服务不可用：提供返回文章或联系入口。
- 图片加载失败：保留项目标题和文字信息，不让卡片塌陷。

## 8. 动效与无障碍

首次加载只执行一次短动效：横幅展开，便签按阅读顺序落位。拍立得、便签和项目相册仅在悬停或键盘聚焦时轻微抬起，不持续漂浮。

- 支持 `prefers-reduced-motion`，关闭入场和位移动效。
- 所有控件使用真实链接或按钮，支持键盘访问和可见焦点。
- 文本与背景满足 WCAG AA 对比要求；浅色便签上的正文使用深色墨色。
- 颜色不作为唯一信息载体。
- 图标按钮提供可访问名称。
- 音乐播放状态和搜索结果数量通过礼貌的实时区域通知辅助技术。

## 9. 数据与内容来源

- 文章、日期、分类和标签继续来自 Hexo 内容模型与 Markdown front matter。
- 精选项目由站点配置中的文章路径列表驱动，避免复制内容。
- 个人简介、学习状态和导航标签由站点或主题配置提供。
- 音乐曲目使用明确配置的本地静态资源；没有资源时进入缺失状态。
- 访问与留言依赖独立、可替换的服务配置。未选择具体服务前，界面提供稳定的禁用状态，不把服务实现耦合进首页模板。

## 10. 文件边界

预计实现会涉及以下边界，具体文件名在实施计划中根据 Stellar 现有结构确认：

- 站点配置：品牌、导航、精选项目、音乐和空间工具盒开关。
- 首页模板：手账三栏结构与 Hexo 数据绑定。
- 自定义样式：颜色令牌、纸张组件、响应式布局、深色模式和减少动态效果。
- 自定义脚本：首页分类交互、工具盒状态、音乐控制与通用键盘行为。
- 文章页覆盖：正文纸张、目录、代码块、作者区和文末导航。

各模块只通过配置和稳定的 DOM 标记通信，避免脚本依赖易变化的视觉选择器。

## 11. 验证计划

实现后至少执行以下验证：

1. 运行 Hexo clean 与 generate，确保无模板或内容生成错误。
2. 检查首页、文章页、分类页、项目页和无结果状态。
3. 在约 1440、1024、768、390 和 320 像素宽度检查布局，无横向溢出或遮挡。
4. 使用键盘遍历导航、搜索、分类、音乐、留言和返回顶部。
5. 验证浅色、夜间手账和系统减少动态效果三种状态。
6. 验证音乐未配置、访问统计未启用和留言不可用时的降级界面。
7. 验证长标题、长代码行、多级目录和图片加载失败场景。
8. 构建后使用浏览器截图做桌面与手机视觉复核，并修正重叠、裁切、对比度和焦点问题。

## 12. 不在本次范围

- 不开发动态后端、用户账户或真实 QQ 登录。
- 不伪造访问量或最近访客数据。
- 不迁移博客框架，也不完整重写 Stellar。
- 不重写现有文章内容。
- 不实现未经选择的第三方统计或留言服务。
- 不为播放器引入流媒体平台或版权不明确的音乐。
