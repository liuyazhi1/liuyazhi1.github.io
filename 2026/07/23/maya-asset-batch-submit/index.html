Maya 资产批量自动提交工具：从手动整理到一键分发的实践

背景与痛点

在影视动画项目里，植被和道具类资产的数量往往非常庞大。在过去的工作流中，艺术家要提交一批资产，得先手动做很多”杂活”：

  1. 手动整理大纲（Outliner）里的节点命名
  2. 手动把贴图归类、摆到正确位置
  3. 因为我们的流程是模型、材质分开提交，所以同一个资产还要分别提交”模型任务”和”材质任务”两个任务

这就带来几个典型痛点：

  • 重复劳动：几百个植被/道具，每个都手动整理一遍，耗时且枯燥
  • 容易漏提交：两个任务分开提，经常会提了模型忘了材质
  • 命名/格式不统一：人肉整理全靠自觉，资产库越来越乱
  • 模型材质对不上：分开提交后，两阶段之间缺乏自动关联，还原时容易错位

这篇文章分享的工具，就是把上面这一整串”整理 + 双任务提交 + 还原”的动作自动化掉。

工具整体流程

核心思路只有一句话：模型与材质分离提交，但用 ABC 做几何载体、用材质 JSON 做”关系说明书”，保证两个阶段最终能对上。

二、两阶段提交：模型与材质分离

这是整个工具最关键、也最巧妙的设计。

2.1 提交前先导出「材质 JSON」

在提交模型之前，工具会先把当前资产的材质信息序列化成一个 JSON 文件，把”哪个模型用了哪个材质球、贴图路径是什么、shader 连接怎么连”都记下来。这个 JSON 就是后面材质还原阶段的”说明书”。

2.2 后台提交模型任务到 Deadline

预处理完成后，工具直接把模型任务提交到 Deadline 渲染农场，而且是后台提交——艺术家不用干等，可以继续干别的。

2.3 等待 Deadline 的成功通知

模型任务不是本地同步等结果的。工具会等待 Deadline 的任务成功通知（事件 / 回调机制），收到”模型任务成功”的信号后，才自动进入材质阶段。这样不需要人工去盯进度。

2.4 模型上传后统一输出 ABC

模型任务成功后，系统会统一输出一份 ABC 缓存。这份 ABC 不带材质，只作为几何载体，供接下来的材质阶段做参考导入。

2.5 提交材质任务：ABC 参考 + 材质还原

材质阶段做三件事：

  1. 把上一步的 ABC 作为参考（reference）导入
  2. import 之前导出的材质球
  3. 根据材质 JSON 把贴图路径和 shader 连接还原回去

全部还原正确后，再提交材质任务。至此，同一个资产的两个任务才算都交完，而且模型与材质是严丝合缝对上的。

三、界面与交互

工具以 Maya 内的自定义 UI（面板 / 窗口）形式提供给艺术家使用：

  • 在视口里选中要提交的一批资产
  • 在面板里点一下按钮
  • 工具在后台跑完整条流程
  • 进度和结果实时显示在面板里

对艺术家来说，复杂的”命名 → 贴图 → 分组 → 双任务提交 → 还原”被收敛成了一个动作。

小结

这个工具把”命名—贴图—分组—双任务提交—材质还原”串成了一条自动化链路，解决的核心问题是：在模型材质必须分离提交的流程下，如何让两阶段自动对齐、不让艺术家做重复手工活。
