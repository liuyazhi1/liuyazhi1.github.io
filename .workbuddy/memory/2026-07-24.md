## 第二篇「UE 提交渲染农场」已收集
- 渲染方式：Movie Render Queue（MRQ）
- 痛点：传统 Deadline 农场不支持"新序列类型渲染"，艺术家只能在自己电脑手动渲染（占机器、无农场并行）
- 解法：新写插件，支持把渲染任务发送到 Deadline 农场，通过命令行方式打开 UE 工程、设置参数、渲染出图
- 插件形态：不提供 MRQ 的 UI 页面，纯命令行提交（与第一篇 Maya UI 工具形成对比）
- 命令行具体参数：用户说"后面补充"，暂缺（等脚本/口头补充）
- "新序列类型"已确认 = UE 的 **Movie Render Pipeline 插件**（Built-In，BETA 1.0）：Advanced movie rendering pipeline，用于渲染电影 / 多媒体；AWS Deadline 不支持该插件的提交 → 艺术家只能本地手动渲
- 插件触发已确认：UE 内**独立提交面板**（非 MRQ 内 UI），可选工程文件/渲染参数/输出路径，点击→连接 Deadline 发送 job
- 文章2 草稿已落地：source/_posts/ue-submit-render-farm.md（命令行参数留占位，待补）
